Demo the full flow

One job, hand to hand, intake to delivery. Switch roles with the dropdown — no login, same data underneath.

  1. Service advisor → New job: register a car (keyboard only — tab / Enter).
  2. On the job page, assign a mechanic — one motion: crew + stage move to Assigned.
  3. Switch to Technician (pick the mechanic you assigned): the job is in the inbox — Accept, then Start work.
  4. Optionally raise a blocker (“Waiting on parts”) → switch to Parts advisor: acknowledge & resolve it.
  5. Back as Technician: Mark done — the job freezes.
  6. Switch to Service advisor: the stage change sits in your inbox — Acknowledge, then Mark delivered.
  7. Workshop manager watches all of it: stage counts, blocked jobs, and unacknowledged handoffs (limbo).
  8. Vehicle owner sees the same truth read-only, via a token link — no login, no actions.
