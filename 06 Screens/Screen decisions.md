# Screen decisions

**One note per screen, holding the *reasoning*: what was settled, what is still open, and what was
rejected and why.** Retrievable by screen rather than by date — the worklog answers *"what happened
on Tuesday"*, these answer *"why is this page like this"*.

Created 2026-08-27 (Session 38) after ruling the Board, when the reasoning for one screen had
landed in four places at once and none of them was findable from the screen.

> [!important] One fact, one place — where this fits
> The **five-home table** — which note holds rules, spec, status, what-exists, and why — lives in
> [[Workflows]] §UI *(moved there 2026-08-31, Session 39, so the whole UI flow reads in one
> place; the table's content is unchanged)*. These notes are the **"why this screen is like
> this"** home.
>
> A screen note **never** carries a tick, a file list, or a rule other screens must obey. If a
> decision here binds every screen, it belongs in [[Design system]] and this note links to it.

**Discipline.** Conclusions are dated. A conclusion that later changes is **not edited** — it gets a
dated footnote saying what changed and whether it narrows or reverses, exactly like a decision
record. *Rejected, with reasons* is the section that earns the note: it is what stops the same
option being re-argued in six months.
