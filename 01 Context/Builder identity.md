# Builder Identity

## Who I am
- Solo builder — I do everything: design, code, and ship.
- Comfortable reading and debugging code.
- I care about building things that work and that I can maintain long-term.

## My stack (summary)
- Ruby on Rails, Hotwire / Turbo / Stimulus, PostgreSQL.
- Default to what Rails provides before reaching for a gem.
- Full detail: [[Tech stack]]

## What I value in code
- Readable — I should understand it 6 months later without comments.
- Reliable — boring, proven patterns over clever new ones.
- Modular — each piece does one thing; easy to delete or replace.
- Minimal surprise — code behaves exactly the way it looks like it should.

## What I avoid
- Over-engineering — no design patterns unless the problem clearly demands it.
- Unnecessary gems — if Rails can do it, use Rails.
- Abstraction for its own sake — no DSLs, no metaprogramming unless unavoidable.
- Premature optimisation — make it work and clear first.
- Code I can't understand — if I have to study it, it's too complex.
